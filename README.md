# English Fluency School

Sistema online de gestão escolar.

## Objetivo
Gerir estudantes, cursos, turmas, pagamentos, recibos, presenças, avaliações e funcionários.

## Identidade visual
- Preto
- Azul-turquesa
- Branco
- Logótipo oficial da escola

## Requisitos
- Acesso online a partir de vários dispositivos
- Base de dados centralizada
- Autenticação segura
- Permissões diferentes para administrador e funcionários
- Interface adaptável a computadores e telemóveis

## Cursos
- Inglês — níveis 1 a 6
- Informática Avançada

## Tecnologias previstas
- React e TypeScript
- Supabase
- Cloudflare

## Estado
Projeto iniciado de raiz.
